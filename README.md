# Chromatix

This is a fork of the [Chromatix](https://github.com/chromatix-team/chromatix) package. This fork uses equinox instead of flax; however the upstream has also switched to equinox in meantime.

Note that this fork has diverged substantially from Chromatix, but is not updated because this would break code that is based on this fork.

The `elements` and `systems` folder were removed and this fork is in general more minimal as the original chromatix.

The grid generation has been changed to return Fourier centered grids everywhere.
